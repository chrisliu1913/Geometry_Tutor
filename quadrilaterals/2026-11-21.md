# Quadrilaterals — November 21, 2026

1. **Warm-up:** In parallelogram ABCD, m∠A = (3x + 10)° and m∠B = (2x + 20)°. Find x and m∠C.
2. **Medium (coordinates):** A(1, 2), B(5, 3), C(6, 7), D(2, 6). Prove ABCD is a rhombus, then show it is NOT a square.
3. **Challenge (proof):** E, F, G, H are the midpoints of sides AB, BC, CD, DA of any quadrilateral ABCD. Prove EFGH is a parallelogram. (Hint: draw diagonal AC.)

<details><summary>Answer key</summary>

1. Consecutive angles of a parallelogram are supplementary: (3x + 10) + (2x + 20) = 180, so 5x = 150 and **x = 30**. m∠A = 100°, and ∠C ≅ ∠A (opposite angles), so **m∠C = 100°**.
2. AB = BC = CD = DA = √17 (distance formula), so ABCD is a rhombus. Slope AB = 1/4 and slope BC = 4; their product is 1, not −1, so AB is not ⊥ BC. No right angle, so it is **not a square**.
3. Draw AC. In △ABC, EF is a midsegment, so EF ∥ AC and EF = ½AC. In △ADC, HG is a midsegment, so HG ∥ AC and HG = ½AC. So EF ∥ HG and EF = HG. One pair of opposite sides is both parallel and congruent, so **EFGH is a parallelogram**.

</details>
